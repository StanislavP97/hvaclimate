# HVA Climate Control

Next.js migration of hvaclimate.com (Webflow → Next.js) for an HVAC contractor
serving Vancouver WA / Portland OR. SEO preservation is the top priority — all
URLs must match the original Webflow site exactly.

See `AGENTS.md` for the AI coding workflow and `blueprint/context/project-overview.md`
for full project context.

## Commands

- Dev server: `npm run dev` (http://localhost:3000)
- Build: `npm run build`
- Production: `npm run start`
- Lint: `npm run lint`
